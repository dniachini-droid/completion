# real-life-rpg (provisional name)

A single-player RPG for one player — Dan — in which meaningful real-life action is the controller.

**Status:** Phase 0 — Player Discovery. Documentation only; no application code yet.

## Where to start

- `docs/CURRENT_STATE.md` — **where the project is right now** and the next action.
- `CLAUDE.md` — permanent project rules.
- `docs/MASTER_BRIEF.md` — the founding document.
- `docs/DECISIONS.md` — decision log.
- `docs/PLAYER_MODEL.md`, `docs/DISCOVERY.md`, `docs/OPEN_QUESTIONS.md` — living discovery documents.

## Layout

```
docs/            project-level: brief, discovery, player model, principles, decisions
docs/game/       game design (loops, progression, economy, quests, collections, balance)
docs/narrative/  world bible, hidden world truth, mysteries, clue ledger, revelation map
docs/product/    product spec, flows, MVP, roadmap
docs/design/     art direction, UX, design system, interaction notes
docs/technical/  architecture, data model, privacy, testing, tech decisions (Phase 7+)
research/        reference material and notes
src/             application code (empty until Phase 8)
```

> `docs/narrative/sealed/` holds the story's hidden truth. **Dan has chosen not to read it** (D-015).
