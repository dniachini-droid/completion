# Phase 5 plan — Concept synthesis

> Work order for Phase 5 (D-042). Spoiler-free: Dan reads this. Sealed story work stays in `narrative/sealed/`.

## The decision
Dan (2026-09-24): no new concepts. The game is the one already chosen and built up over Phases 2–4: the loop *Explore · Decode · Connect* (D-010), the story (D-024), the tools (D-020, D-023), the look D (D-032, D-040). Phase 5 writes that one concept up properly, checks it holds together, and settles the numbers the build needs. It does not redesign anything already agreed.

## Output
**`product/CONCEPT.md`**: one readable page (ten-minute read) that a builder could work from, under MASTER_BRIEF §59's headings for this one concept: the player fantasy, a day of use, the core loop, the story (player-safe), collection, progression, the real-life connection, strengths, risks, longevity, how hard it is to build. It links to the detailed docs rather than copying them.

## Steps (in order)
1. **Write `product/CONCEPT.md`** from the agreed docs (`game/`, `design/`, `DESIGN_PRINCIPLES.md`, the game bible). Nothing new invented.
2. **Stress-test it**: every mechanic against the principles, the anti-features and the §71 checklist; walk through a low day, a normal day, a high day, an interrupted delve, a week away, and a disrupted week. Fix any gap with the smallest rule that works and log it.
3. **Settle the numbers** (starting guesses, tuned in play):
   - region sizes, how far apart named places are, and step pacing (D-037), with enough route past every opened place for Dan's real hours (D-037, D-039);
   - the reward rhythm: what Dan is guaranteed to get per delve, per day, per week (D-035);
   - high-energy days: what extra effort always unlocks (D-035, D-011);
   - memory and recap, so a story told in small pieces stays remembered, and the before → now view for re-reading (D-035).
4. **Write the first playable's contents list**: what's in and what's out, from the draft in `game/GAME_DESIGN.md`, sized for 5–6 weeks of play (D-023). This feeds Phase 6 (MVP).
5. **Dan reviews** the concept page and the numbers. Claude asks him only about taste and priorities.
6. **Close Phase 5** with Dan's agreement: merge into `main`; Phase 6 opens in a new session.

**In parallel, in its own session (before the first playable is built):** the sealed story-fix session (D-035). Claude does it alone; Dan's view stays spoiler-free.

## Not in Phase 5
Code, tech stack, or new mechanics beyond what the stress test shows is needed (rule 12). Any more visual changes to D.
