# Anti-Features

> Deliberate exclusions and why. Protects against feature creep. Refined in Phase 1.

Seeded from the founding brief (MASTER_BRIEF §16–19, §23). Each will be reviewed with reasons during Phase 1.

| Excluded | Why (from brief) |
|---|---|
| Punitive streak loss | Failure must generate information, not shame. |
| Lost levels / equipment / dead companions / destroyed settlements for missed tasks | Same hard rule. |
| Disappointed NPCs, guilt language, hostile motivation | Same hard rule; also no sycophancy the other way. |
| XP for trivial task spam | Task farming must not out-earn meaningful effort. |
| Endless / many currencies | Currencies need a real purpose, source and sink. |
| Notification spam / daily guilt notifications | Guilt engine anti-goal. |
| Manual estimation / tagging / scoring of every task | Productivity theatre. |
| Complex life-management dashboard | Next action must be obvious. |
| Social features, teams, billing, public profiles, broad onboarding | Built for Dan, not a market. |
| Live AI-generated lore without canon control | Continuity. |
